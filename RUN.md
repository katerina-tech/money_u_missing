# Как запустить проект

Практическая инструкция. Архитектура и продуктовые решения — в
[`README.md`](README.md) и [`docs/`](docs/).

**Ключевой факт:** ключи API не нужны. С пустым `.env` работает весь продукт —
14 демонстрационных возможностей и 2 реальные программы, детерминированный
матчинг, Germany check с цитатами, корпус немецкого законодательства,
калькуляторы, трекинг и все тесты.

---

## Что должно быть установлено

| Инструмент | Версия | Проверка |
|---|---|---|
| Python | 3.12+ | `python --version` |
| Node.js | 22+ | `node --version` |
| uv | любая свежая | `uv --version` |

Если `uv` не найден — установите: <https://docs.astral.sh/uv/>

`make` **не нужен.** Он отсутствует на обычной установке Windows, поэтому все
задачи продублированы кросс-платформенным скриптом `scripts/tasks.py`, а
Makefile просто вызывает его. Ниже везде используется скрипт.

---

## Запуск

Из корня репозитория:

```bash
python scripts/tasks.py setup
```

Устанавливает обе половины из зафиксированных lock-файлов, генерирует данные,
применяет миграции и заполняет базу. Занимает несколько минут. Нужно **один
раз**.

```bash
python scripts/tasks.py dev
```

Поднимает оба сервера:

- **<http://localhost:3000>** — веб-приложение
- **<http://localhost:8000/docs>** — API, Swagger UI

Откройте `http://localhost:3000` и нажмите **Build my Money Map**. Регистрация
не требуется — демо-сессия создаётся одним кликом.

Первая сборка Next.js занимает 20–40 секунд. Дождитесь строки `Ready` в
терминале, до неё страница может не отвечать.

Остановить — `Ctrl+C`. Гасятся оба сервера сразу.

### Половины по отдельности

Иногда удобнее два терминала — например, чтобы перезапускать фронтенд, не трогая
API:

```bash
python scripts/tasks.py dev-api
```

```bash
python scripts/tasks.py dev-web
```

## Все задачи

```bash
python scripts/tasks.py --help
```

| Задача | Что делает |
|---|---|
| `setup` | Установка обеих половин, генерация данных, миграции, заполнение базы |
| `dev` | API на :8000 и веб-приложение на :3000 |
| `dev-api` / `dev-web` | Только одна половина |
| `test` | Юнит-тесты бэкенда и фронтенда |
| `e2e` | Playwright end-to-end (нужен запущенный API) |
| `eval` | Набор AI-оценок на скриптованном провайдере |
| `check` | Всё, что гоняет CI: lint, typecheck, test, eval |
| `lint` / `format` / `typecheck` | По отдельности |
| `build` | Production-сборка веб-приложения |
| `docker-build` | Сборка обоих образов |
| `data` / `migrate` / `seed` | Шаги `setup` по отдельности |
| `clean` | Удалить артефакты сборки и кэши. Базу не трогает |
| `reset` | Удалить локальную базу и собрать заново. **Уничтожает локальные аккаунты** |

## Проверка перед защитой

```bash
python scripts/tasks.py check
```

Прогоняет lint, `mypy --strict`, 180 тестов бэкенда, 25 фронтенда и 42
оценочных кейса. Ни один не делает платного вызова модели — поэтому это
безопасно запускать вживую перед аудиторией.

End-to-end тесты идут отдельно, потому что им нужен работающий API. В одном
терминале `dev`, в другом:

```bash
python scripts/tasks.py e2e
```

## Если что-то не работает

### `File does not exist: app.py`

Это не Streamlit-проект. Он состоит из FastAPI-бэкенда и Next.js-фронтенда,
файла `app.py` в корне нет. Запускайте `python scripts/tasks.py dev`.

### Активировать виртуальное окружение не нужно

`tasks.py` сам находит интерпретатор в `backend/.venv`. Активация не вредит, но
и не требуется. Если PowerShell отказывается выполнить `Activate.ps1` — просто
не активируйте.

### `'uv' is not on PATH` / `'npm' is not on PATH`

Инструмент не установлен или окно терминала открыто до установки. Установите и
откройте терминал заново — PATH подхватывается при старте оболочки.

### Порт занят

```bash
python scripts/tasks.py dev-api
```

и отдельно фронтенд на другом порту:

```bash
cd frontend && npx next dev --port 3001
```

Тогда укажите фронтенду, где искать API, через `NEXT_PUBLIC_API_BASE_URL` в
`frontend/.env.local`.

### База в странном состоянии

```bash
python scripts/tasks.py reset
```

Удаляет локальную базу и собирает заново. Локальные аккаунты и сохранённые
возможности пропадут — для демо это обычно то, что нужно.

### Проект лежит в OneDrive

Он работает, но синхронизация конфликтует с папками зависимостей.
`frontend/node_modules`, `backend/.venv` и `frontend/.next` — это около
900 МБ и 22 000 файлов, которые OneDrive не может синхронизировать и помечает
красным крестиком. Ничего из этого не отслеживается git и всё восстанавливается
командой `setup`.

По той же причине в `backend/pyproject.toml` стоит `link-mode = "copy"`:
OneDrive отказывается создавать жёсткие ссылки внутри синхронизируемой папки
(ошибка 396).

Надёжнее перенести проект за пределы OneDrive, например в `C:\dev\`.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните — но только если хотите
дополнительные возможности. Что они добавляют:

| Переменная | Что включает | Без неё |
|---|---|---|
| `ANTHROPIC_API_KEY` | Разбор CV, написанные объяснения оценок | Ручное заполнение профиля, объяснения из шаблонов |
| `MYM_DATABASE_URL` | Postgres + pgvector | SQLite с векторным поиском на numpy |
| Ключ поискового провайдера | Живой поиск возможностей | Демо и курируемые записи |
| `MYM_JWT_SECRET` | Сессии переживают перезапуск | Эфемерный ключ на процесс |

Приложение сообщает в интерфейсе, какие функции работают в урезанном режиме —
эндпоинт `GET /api/capabilities`.

**`.env` в `.gitignore` и никогда не попадает в логи.**
